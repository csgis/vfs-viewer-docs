# Bedienungsanleitung für VfS Viewer

Diese Anleitung bietet eine Erläuterung zu den verschiedenen Inhalten der Applikation (z.B. Navigation, Informationsabfrage, Visualisierung, Grundlagendaten, etc.).

# Startseite

Die Startseite bringt Sie sowohl zum öffentlich zugänglichen (**VfS Viewer**), sowie zum Passwort geschützen Bereich (**VfS Viewer Plus**) des VfS Viewers.

Mit Klick auf “Öffentliche Karte“ landen Sie direkt auf der “Karte“. Hier sieht man alle thematischen Ebenen des VfS Viewers, die nach Themen gruppiert sind. Mit einem “Schloss“ markierte Bereiche (zum Beispiel alle Daten in der Gruppe Waldbodeninformationen), sind erst nach erfolgter Passworteingabe einsehbar.

Authentifizierte User haben damit die Möglichkeit, den **VfS Viewer Plus** zu verwenden. Neben allgemeinen Themen, lassen sich dort auch die Informationen zur Standortskarte und zur Baumarteneignung darstellen. Die Anzeige wird dabei auf das Hoheitsgebiet der angemeldeten WBV beschränkt, so dass keine Fremddaten eingesehen werden können.

Einen weiteren Unterschied zum allgemeinen **VfS Viewer** stellt die Hintergrundebene dar. Der VfS Viewer Plus bietet die Möglichkeit sich die amtlichen Daten der Landesvermessung zuzuladen.

Der Zugriff auf den VfS Viewer Plus ist kostenpflichtig. Bei Interesse an der Nutzung des “VfS Viewer Plus“ nehmen Sie bitte Kontakt mit der Geschäftsstelle des VfS  ([www.vfs-muenchen.de](http://www.vfs-muenchen.de/)) auf.
